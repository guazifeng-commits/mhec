1 软件简介

1.1 概述

M-HEC(MLFF-Enhanced High-temperature Elastic Constants)是一款面向材料计算研究人员的、用于 在第一性原理精度下高效计算材料有限温度(尤其是高温)弹性常数及力学性质的一体化命令行软件。

要解决的问题。 弹性常数是材料力学性能、相稳定性、热力学与声学性质的基础物理量。传统上有两条路线各有短板: 静态 DFT 只能给出 0 K 结果,无法反映高温软化;纯第一性原理分子动力学(AIMD)虽能包含温度效应,但在 高温、大超胞、长时间采样下计算代价极其高昂,往往难以承受。M-HEC 通过引入 VASP 的 机器学习力场(MLFF),在保持 DFT 精度的同时把分子动力学采样成本降低若干数量级, 使"高温、有限温度弹性常数"的规模化计算成为可实践的常规流程。

核心工作方式。 软件对平衡结构施加一系列已知微小应变,用训练好的 MLFF 在各温度下做长时间 NVT 分子动力学采样,提取时间平均应力,再以应力-应变法拟合出完整的 6×6 弹性常数矩阵;随后自动完成 对称化、残余压力修正、Born 稳定性判据,并一站式导出 VRH 多晶模量、方向性各向异性曲面、德拜温度、声速 等力学与热力学性质,同时提供可直接用于 Origin 作图的数据文件。

使用体验。 软件采用单层交互式菜单,所有功能平铺呈现、无需记忆命令; 配合 SLURM 集群一键提交脚本与自动任务依赖(NPT 优化 → 结构更新 → NVT 采样), 覆盖从力场训练、精度验证、输入生成、任务提交、应力提取、弹性拟合到力学/AIMD 后处理的完整闭环。 面向从事金属、合金、共价晶体、离子晶体、陶瓷、液态/熔体等体系高温力学性质研究的用户。

1.2 主要功能

M-HEC 按"力场 → 计算 → 后处理"的科研流程组织功能,主要包括六大模块:

  • 弹性常数计算(核心):提供 SC-SS(单分量)与 SA-SS(对称化)两种应力-应变方案, 覆盖全部 9 个晶系(三斜/单斜/正交/四方 4-mmm 与 4-m/三方 -3m 与 -3/六方/立方); 自动识别晶系与最小充分变形集、按对称性生成变形结构、提取应力、拟合、对称化、残余压力修正、Born 稳定性判据; 支持多温度批量一次性生成与提交。
  • MLFF 力场训练:两种训练策略——定温网格训练(在多个温度点分别采样)与 升温连续训练(一条升温轨迹覆盖整个温区并顺序续训);均采用应变增强训练, 在训练集中注入弹性应变构型以覆盖弹性线性区;训练/采样应变域自洽对齐;LANGEVIN_GAMMA 按元素种类自动展开; 物理参数(泛函、色散校正、展宽等)继承用户 INCAR。
  • 力场精度验证:解析 ML_LOGFILE 给出训练集 RMSE、贝叶斯误差与精度评级; 基于 ML_AB 的全数据集 parity 验证,对能量/力/应力逐一给出 RMSE/MAE/R² 与散点图。
  • 力学性质后处理:由弹性矩阵计算 VRH(Voigt/Reuss/Hill)多晶体/剪切/杨氏模量与泊松比、 各向异性指数(通用 AU、Zener)、方向性 E/G/ν/线压缩率的 3D 各向异性曲面与 2D 截面极图、 德拜温度、纵横声速与 Christoffel 方向声速、Clarke 最小热导率;所有图均附 Origin 数据。
  • AIMD 后处理:对分子动力学轨迹做结构与输运分析——总/偏径向分布函数 RDF、 均方位移 MSD 与扩散系数(可分元素)、速度自相关 VACF 与声子态密度 PDOS、 Green-Kubo 粘度(块平均 + Bootstrap 置信区间)、静态结构因子 S(q)、配位数、键长键角分布、静水压力统计。
  • 辅助工具:晶系/空间群识别与晶格参数、化学式/摩尔质量/密度计算、 变形模式与应变方案预览、平衡晶格提取与热膨胀系数计算。

1.3 技术特色

  • 精度MLFF 在 DFT 精度下实现高温大规模采样,兼顾精度与效率。
  • 全晶系三斜、单斜、正交、四方、三方、六方、立方等 9 个晶系均自动适配对称化与 Born 判据。
  • 去偏置默认采用过原点奇多项式(立方)拟合提取零应变切线,消除有限温 MD 应力-应变曲线的非谐偏置。
  • 一致性弹性计算强制使用同一已训练力场(ML_MODE=run)跑所有变形目录,保证结果自洽。
  • 压力修正Wallace/Brugger 残余压力修正,给出可与实验对比的推荐弹性常数。
  • 参数继承训练/计算的 INCAR 自动继承用户提供的物理参数(泛函 GGA、色散校正 D3、ISMEAR/SIGMA、LDAU、磁矩等),仅强制改写会破坏 MD/ML 流程的控制参数,适配不同材料体系。
  • 自动化SLURM 一键提交,自动编排"NPT 晶格优化 → 用优化晶格更新变形结构 → NVT 弹性采样"的任务依赖链。
  • 数据友好所有图形结果同时导出 Tab 分隔、带表头、按 Cij 命名的 Origin 数据文件,便于二次作图与制表。
  • 鲁棒提取应力提取同时解析 vasprun.xml 与 OUTCAR 并取帧数更多者,兼容 DFT 与 MLFF-run 输出格式;跳过步数越界时自动改用后半段。
  • 可复现工作目录自动保存 mhec.yaml,拟合时按其参数复现。
  • 中英双语菜单、提示、报告与日志支持中/英文界面(MHEC_LANG 或设置菜单切换,可永久保存),便于国际使用与投稿。

一个完整的高温弹性常数研究通常按如下顺序进行:

1.6 适用范围与限制

重要物理限制(经典分子动力学的固有局限): M-HEC 基于经典核的 MLFF-MD,不包含核量子效应。对于德拜温度极高的材料(如金刚石,θD≈2000 K), 在温度远低于 θD 时,经典 MD 会高估热膨胀、并使弹性常数的温度依赖(dC/dT)在低温段失真。 高温段(T ≳ θD/2)结果更可靠。若需低温精确的温度依赖,建议改用准简谐近似(QHA)或路径积分 MD(PIMD)。 详见第 11 章 FAQ。

2 理论背景

2.1 应力-应变法计算弹性常数

弹性常数 Cij 描述晶体应力 σ 对应变 ε 的线性响应,由广义胡克定律 σi = Σj Cij εj(Voigt 记法,i,j = 1…6)给出。 M-HEC 对平衡结构施加一系列已知的小应变,在每个变形构型上用 MLFF-MD 采样得到时间平均应力, 再对应力-应变曲线在零应变处求斜率,即得到相应的弹性常数分量。

有限温度下,弹性常数取自 NVT 系综中变形结构的平均应力,因此天然包含温度效应(热软化)。

2.2 MLFF 加速的高温采样

纯 AIMD 在高温、大超胞、长时间采样下代价极高。M-HEC 借助 VASP 的机器学习力场:先用少量 DFT 步训练力场 (ML_MODE=train),再用训练好的力场以接近经典 MD 的成本进行长时间采样(ML_MODE=run), 在保持 DFT 精度的同时把采样成本降低若干数量级。

关键:训练域与采样域自洽。 弹性采样所用的应变幅度必须落在力场训练时见过的应变范围内, 否则力场进入外推区、应力不可靠。M-HEC 默认弹性采样最大应变为 0.02(见 §2.4),与默认训练应变集 (0.005 / 0.01 / 0.02)对齐。

2.3 SC-SS 与 SA-SS 两种变形方案

两者本质都是应力-应变法,区别在于施加应变的"基":

方案全称变形基特点
SC-SS单分量应力-应变法
(Single-Component)		 逐个施加单一 Voigt 应变分量(如仅 ε1、仅 ε4) 通用,支持全部 9 个晶系;每个变形直接对应矩阵的一列。
SA-SS对称化应力-应变法
(Symmetry-Adapted)		 按晶系对称性组合的应变模式(如体积、正交、剪切等) 用更少的变形模式高效获取独立常数;每个模式对应某个 Cij 组合(如 C11+2C12、C11−C12、2C44)。

软件内部与旧工作目录兼容,SA-SS 的配置键仍沿用 vc、文件前缀仍为 vcfit_。

2.4 奇多项式拟合与非谐偏置修正

有限温度下单轴应变的应力-应变曲线存在非谐性:若直接做线性拟合,曲线中的偶次(ε²)或高次项会 系统性地偏置斜率(例如金刚石 C12 被显著高估)。M-HEC 默认使用 过原点奇多项式拟合 σ = C1·ε + C3·ε³,取一次项 C1 作为零应变切线斜率, 从而消除非谐偏置。当数据点少于 4 个时自动退回线性拟合。该行为由参数 fit_poly_order 控制(默认 3;设为 1 则强制线性)。

由于采样点关于零点对称(±0.01、±0.02)且奇基函数与偶分量正交,偶次(压缩/拉伸不对称)项不会污染 C1, 因此奇多项式拟合对体积/单轴等模式都稳健。

2.5 Wallace 残余压力修正

高温平衡构型往往存在残余静水压力 P。M-HEC 依据 Wallace 理论,把对称化后的 Birch 弹性常数 修正为 Brugger 弹性常数(考虑残余压力贡献),并在报告中给出诊断。 当 |P| 显著(> 0.5 GPa)时,elastic.txt 保存 Brugger 推荐值,同时另存 elastic_birch.txt 供参考。

2.6 力学性质与热力学量

由 6×6 弹性常数矩阵可进一步导出:

  • VRH 多晶模量:体模量 K、剪切模量 G(Voigt/Reuss/Hill),及杨氏模量 E、泊松比 ν。
  • 各向异性:通用各向异性指数 AU、Zener 指数(立方)、K/G 各向异性。
  • 方向性性质:方向杨氏模量、剪切模量、泊松比、线压缩率的 2D/3D 各向异性曲面。
  • 热力学量:德拜温度 θD、声速(纵/横及 Christoffel 方向声速)、最小热导率(Clarke 模型)。
  • Born 稳定性:按晶系判据 + 正定性检验判断力学稳定性。
德拜温度与声速依赖密度和每原子平均摩尔质量;M-HEC 会自动从工作目录的 POSCAR 推算并预填, 请勿沿用无意义的默认值(如密度 5.0、摩尔质量 50.0),否则 θD、声速会失真。

4 快速开始(金刚石完整算例)

本章以金刚石为例,演示从力场到高温弹性常数的完整流程。假设已有一个训练好的力场 ML_FF。

步骤 0:准备输入文件

在一个工作目录中准备以下文件(见第 6 章):

POSCAR    POTCAR    KPOINTS    INCAR    ML_FF    run.sh

步骤 1:生成弹性常数计算输入(菜单 1)

6 输入文件准备

弹性常数完整工作流(菜单 1/3)要求在当前目录准备下列文件:

文件必需说明
POSCAR是平衡结构;务必包含元素符号行(第 6 行),否则无法算密度/摩尔质量。
INCAR是用户提供的 VASP 参数模板;M-HEC 继承其物理参数,仅强制改写会破坏 MD/ML 流程的控制参数。
POTCAR推荐赝势文件,自动复制到各计算目录。
KPOINTS推荐k 点文件,自动复制。
ML_FF推荐预训练力场;存在时弹性计算自动强制 ML_MODE=run。
run.sh推荐SLURM 作业脚本,自动复制到各目录,由 submit_all.sh 调度。

INCAR 参数继承规则

M-HEC 会读取用户 INCAR,把除受管控制参数以外的所有键(如 ENCUT、PREC、EDIFF、ALGO、LREAL、ISMEAR、SIGMA、 GGA、IVDW/VDW_*、LDAU*、ISPIN、MAGMOM 等)全部继承,以适配不同体系(金属/绝缘体/含 D3 校正等)。 只有会破坏工作流的参数被强制改写: 

受管(强制)参数:IBRION / MDALGO / ISIF / NSW / TEBEG / TEEND / POTIM /
                 SMASS / PMASS / PSTRESS / LANGEVIN_GAMMA(_L) / ISYM / LWAVE / LCHARG,
                 以及全部 ML_* 前缀参数
LANGEVIN_GAMMA 会按元素种类数量自动展开(每元素一个值);若用户给的值个数不足,按最后一个值补齐。
务必用同一已训练力场计算所有变形。 弹性常数要求各变形目录使用相同的力场(ML_MODE=run)。 若目录里各自 ML_MODE=train 在线训练,会得到互不一致的力场,弹性常数将失去物理意义。检测到 ML_FF 时软件自动处理; 未检测到会给出警告。

7.3 机器学习力场(菜单 7–9)

菜单 7:MLFF 训练(定温)

作用:在多个温度点上训练力场,并注入弹性应变构型以覆盖弹性线性区。

要点:

  • 读取用户 INCAR,继承物理参数(GGA、D3、ISMEAR 等),仅强制 MD/ML 控制参数;
  • 默认训练应变集 [0.005, 0.01, 0.02],与弹性采样最大应变 0.02 对齐;
  • NPT 分支的 LANGEVIN_GAMMA 按元素数展开。

弹性训练模式(auto / general)——决定 Phase B 训练时施加哪些应变方向:

模式施加的应变集适用
auto(默认)按当前晶系对称性给出的最小充分应变集(如立方 4 个、六方/四方 7–8 个、正交 10 个)推荐,既充分又不浪费
general不裁剪的全 Voigt 基(xx/yy/zz 单轴 ±、yz/xz/xy 剪切 ±、体积 ±,共 14 个)不信任自动识别、或担心高温对称性破缺时的保险选项;代价是目录/计算量更大
对给定晶系,auto 已足以覆盖全部独立弹性常数;general 的额外方向属冗余采样,不会提升该晶系结果精度,只是更保险。

11 常见问题与注意事项(FAQ)

Q1. 金刚石的热膨胀/低温弹性常数为什么和实验对不上?

经典 MD 不含核量子效应。金刚石德拜温度极高(≈2000 K),在 300–1500 K 远低于 θD,量子效应显著。 表现为:热膨胀在低温被严重高估(经典给出近乎常数的高温平台值);弹性常数的温度依赖(dC/dT)在低温段失真。 好在弹性常数随温度变化本身很小(几个%),故 300 K 绝对值误差通常仅 1–2%。建议:高温段结果可信; 要低温精确斜率请用 QHA 或 PIMD。

Q2. 如何保证不同温度的弹性常数正确?

  1. 0 K 静态对标:用同一力场在 0 K 静态结构上算弹性常数,与 DFT/实验对比(锚点)。
  2. MLFF 应力精度:确认变形构型上的 stress parity RMSE 足够小(菜单 9)。
  3. 收敛性:应变幅度在线性区、采样步数足够、超胞与 k 点收敛。
  4. 趋势自检:Cij 随 T 单调平滑软化;必要时 SC-SS 与 SA-SS 交叉验证。
  5. 零压平衡:各温度 NPT 收敛到零压(Wallace 诊断 |P| 小)。

Q3. 拟合图里 0.02、0.03 点越来越偏,怎么办?

主因是 MLFF 外推(采样应变超出训练域)和有限应变非谐。对策:把弹性采样最大应变控制在训练域内 (默认 n_points=5 → 最大 0.02);必要时进一步减小 δ(如 0.008/0.006);保持奇多项式拟合以取零应变切线; 或在 0.01/0.02 应变构型补训练数据。

Q4. C12 偏高?

单轴应变应力-应变曲线的非谐(奇次立方)项会偏置线性拟合。M-HEC 默认的奇多项式(立方)拟合已修正此问题;确保 fit_poly_order=3。

Q5. 应该用 PBE 还是 PBEsol / 是否加 D3?

PBEsol 对致密固体的晶格常数与弹性常数通常更好;D3 色散校正主要对层状/分子/范德华体系关键,共价/金属体系一般无需。 泛函与 D3 参数请写在用户 INCAR 中,M-HEC 会自动继承。若之前训练力场时 INCAR 漏带泛函/D3,建议用新版重训力场。

Q6. 力学后处理里密度/摩尔质量该填什么?

软件会从工作目录 POSCAR 自动预填密度与每原子平均摩尔质量(德拜温度所需)。请勿沿用默认 5.0 / 50.0。POSCAR 必须含元素符号行。

Q7. VASP 报 MPI / 内存相关错误?

  • 单节点端口异常:设 I_MPI_FABRICS=shm;多节点用 FI_PROVIDER=tcp 或排除故障节点。
  • OOM(SIGKILL/SIGBUS):每节点减少 rank、增大内存、设置 NCORE、大超胞用 LREAL=Auto、检查 /dev/shm。

Q8. 空间群没有显示?

空间群识别依赖 spglib。运行 pip install spglib 后即可在菜单 10 显示;未安装不影响其他功能。
